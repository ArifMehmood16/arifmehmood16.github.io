# Arif Mehmood

Personal site of Arif Mehmood, AI engineer. Live at [arifmehmood16.github.io](https://arifmehmood16.github.io).

## Development

Requires Node.js 22+ and npm.

```sh
npm i
npm run dev
```

The app runs at [http://localhost:8080](http://localhost:8080).

## Build

```sh
npm run build
```

Static files land in `dist/client` and are deployed to GitHub Pages from `main`.

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
